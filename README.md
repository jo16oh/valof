# Valof

[![npm](https://img.shields.io/npm/v/valof.svg)](https://www.npmjs.com/package/valof)

> **Values are plain data; behaviour lives outside them.**

Value-object helpers for TypeScript. Read the [documentation](docs/README.md).

```bash
pnpm install valof
```

# Development

```bash
vp install              # install dependencies
vp test                 # run the tests
vp check                # format, lint, type check
vp pack                 # build
vp run bundle-size      # measure the bundle against its budget
vp run type-perf        # measure the typecheck performance
vp run ts-compatibility # type check the published .d.mts against every TypeScript line
```
